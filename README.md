🤖 ARC Robotics Website

A modern, dynamic, and scalable website built for the ARC Robotics Club to showcase events, team members, and learning resources — all managed without touching code.

🚀 Live Demo

🔗 https://arc-robobtics-bfgk.vercel.app/

✨ Features
🗓️ Interactive Event Timeline
Explore past and upcoming events with detailed popups and visuals
👥 Dynamic Team Section
Easily manageable team member showcase powered by CMS
📚 Study / Resources Section
Centralized learning material related to robotics and club domains
⚡ No-Code Content Management
Add/update events, members, and resources without editing code
🎨 Modern UI/UX
Clean design with smooth animations and responsive layout
🛠️ Tech Stack
Frontend: Next.js, React, Tailwind CSS
Backend / CMS: Sanity (Headless CMS)
Deployment: Vercel
📦 Installation & Setup

Clone the repository:

git clone https://github.com/your-username/arc-robotics-website.git
cd arc-robotics-website

Install dependencies:

npm install

Run the development server:

npm run dev
